# Brand — Lineage

The company brain that knows *why*, *who*, and *what went stale* — an AI agent whose memory is a knowledge graph.

_Generated by `brand-design` skill on 2026-10-15. Update by re-running the skill._

## Palette — Graphite

**Vibe:** minimal · serious · professional
**Category:** ai/tech (knowledge graph, agent tooling)
**Mood:** minimal + serious

Grayscale with intent. The brand carries no hue, so meaning is never carried by
color alone — status is expressed by the semantic tokens below plus icon and
label. This keeps the product legible for long working sessions and lets
knowledge graph data (the only place color appears) own the visual field.

## Typography — Geist headings + Inter body + Geist Mono numerics

- **Display (h1–h3):** Geist — `--font-display`
- **Body + UI:** Inter — `--font-sans`
- **Mono (numbers, node ids, Cypher):** Geist Mono — `--font-mono`

Wired via `next/font/google` in `app/layout.tsx` (build-time inlined, no FOUT).
A `.tabular` helper (`font-mono` + `tabular-nums`) exists in `globals.css` for
any number that updates in place.

## Gradients

Two gradients, deliberately neutral — a monochrome brand has no hue to shift,
so these are a graphite sheen rather than a color fade. Exposed as
`bg-brand-bg` and `bg-brand-accent` (Tailwind v4 background-image utilities).

### Background gradient (subtle)

```css
/* dark */ --gradient-bg: linear-gradient(135deg, oklch(0.12 0 0) 0%, oklch(0.15 0 0) 100%);
/* light */ --gradient-bg: linear-gradient(135deg, oklch(0.99 0 0) 0%, oklch(0.955 0 0) 100%);
```

**Use for:** the landing hero, page mastheads, the empty graph placeholder.
**Do not use for:** body text backgrounds, cards, form fields.

### Accent gradient

```css
/* dark */ --gradient-accent: linear-gradient(to right, oklch(0.88 0 0) 0%, oklch(0.62 0 0) 100%);
/* light */ --gradient-accent: linear-gradient(to right, oklch(0.45 0 0) 0%, oklch(0.3 0 0) 100%);
```

**Use for:** the landing CTA, a single premium badge, the top border of the
answer panel. Never as a body-text background — keep text on `--card`.
Midpoint contrast with the paired foreground is ≥ 7:1 in both themes.

## Tone and voice

Lineage speaks like a senior engineer who has the receipts: specific, calm, and
willing to say "I don't know."

### Words to use

Direct, specific, factual. Name the artifact (`ADR-014`, `D-001`, `PAY-231`).
State what a feature does, not how impressive it is. Prefer short declaratives:
"Every answer shows the path it came from." Numbers over adjectives.

### Words to avoid

Hype (revolutionary, game-changing, unleash, supercharge, seamless), emojis in
product copy, exclamation marks, "simply", "just", "easy", "powerful". Never
imply certainty the graph does not support — the product's whole promise is that
a claim without a path is not an answer.

### Voice example

> "Sessions moved to Postgres in Oct 2026. This decision supersedes D-001.
> 7 downstream nodes are now stale — 3 tickets, 2 runbooks, 1 onboarding doc,
> 1 PR. Owners have been drafted an update task."

## Usage dos and don'ts

**Do:**

- Use the shadcn CSS variables (`bg-background`, `text-foreground`, `bg-primary`,
  `text-stale`) everywhere. Never hardcode hex in a component.
- Keep the 4 px spacing grid (`gap-2`, `p-4`, `px-6`).
- Toggle the `.dark` class on `<html>` — dark is the default theme.
- Use `.tabular` / `font-mono tabular-nums` for counts, ids, and live numbers.
- Pair every status color with an icon and a label (Section 10 rule).
- Test each component in both themes at 375 / 768 / 1280 px.

**Don't:**

- Hardcode colors (`#A4A4A4`, `rgb(...)`) in component files.
- Use `transition: all` — specify `transition-colors`, `transition-transform`.
- Mix both gradients on one screen.
- Put body text on the accent gradient.
- Override tokens per-component — fix them once in `globals.css`.
